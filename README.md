# Профпартнер
Лендинг и каталог находятся в site/. Сборка через python3 build.py создаёт Worker с локальными ресурсами и обработчиком POST /api/request. Заявки сохраняются в закрытом R2 BUCKET в requests/. Уведомления менеджеру требуют подключения канала. Контакты, четыре позиции, логотип и документы ожидают материалов клиента. Фотографии иллюстративны.
